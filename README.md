# NEXUS.AI — Interactive AI/ML Profile & System Demonstrator
### Architected by Dr. Alex Vance, Ph.D. | Principal AI/ML Architect (10+ Yrs Exp)

An interactive, production-grade Artificial Intelligence and Machine Learning profile website engineered with zero external framework overhead, featuring real-time in-browser neural computation, high-throughput MLOps telemetry, and an interactive industry ecosystem radar directly realized from multi-domain enterprise blueprints.

---

## 🌟 Key Architecture & Features

### 1. Interactive AI/ML Industry Ecosystem Radar (Matching Architecture Diagram)
- **Central AI/ML Core Hub**: Pulsing high-throughput inference engine with interactive rotation and telemetry inspection.
- **7 Satellite Industry Nodes**:
  1. 🛒 **Smart Retail & E-Commerce**: Multi-armed bandit RecSys, sub-12ms latency, +34% conversion lift.
  2. 📈 **Predictive Analytics & Quantitative Growth**: Temporal Fusion Transformers, 96.8% forecast accuracy.
  3. 👥 **Talent Intelligence & Conversational AI**: RAG-augmented resume knowledge graphs, -62% time-to-hire.
  4. 🏛️ **Fintech, Banking & Governance**: Heterogeneous Graph Neural Networks (GNN) for sub-4ms anti-fraud.
  5. 🏥 **Medical AI & Clinical Diagnostics**: 3D Swin-UNETR volumetric MRI segmentation with HIPAA federated privacy.
  6. 🚚 **Autonomous Logistics & Smart Supply Chain**: Deep RL (PPO) Vehicle Routing Problem solver (-22% fuel spend).
  7. 🏭 **Smart Factory & Industrial IoT**: 240 FPS edge vision defect detection on NVIDIA Jetson AGX Orin (<25W).

### 2. Live In-Browser Mini-Labs
- **Lab 1: 2D Neural Network Classifier**:
  - Live backpropagation and gradient descent in pure JavaScript.
  - Interactive datasets: Concentric Circles, Twin Spirals, XOR, Interleaved Moons.
  - Real-time decision boundary canvas rendering and loss curve sparkline.
- **Lab 2: LLM Tokenizer & 2D Semantic Vector Space**:
  - Subword BPE tokenization simulation with token IDs and byte counts.
  - Token-to-FLOP computation estimator (LLaMA-3 / Mistral benchmark).
  - 2D Cosine similarity projection against benchmark embedding vectors.
- **Lab 3: Edge Computer Vision & Defect Detection**:
  - Real-time camera stream simulation (PCB Solder QA, Clinical MRI, Retail Checkout, Fleet Telematics).
  - Dynamic confidence ($\tau_{conf}$) and Non-Max Suppression IoU sliders.
  - Telemetry counters: FPS, Latency (ms), and INT8 calibration status.
- **Lab 4: MLOps Streaming Drift & Chaos Engineering**:
  - Live streaming metric canvas monitoring Kolmogorov-Smirnov distribution drift.
  - Interactive injection buttons for concept drift and outlier spikes.
  - Automated Ray-Train fine-tuning trigger and shadow model promotion.

### 3. Interactive AI Twin / Virtual Interview Copilot
- Conversational assistant embedded directly into the page.
- Responds with architectural trade-offs, quantization strategies (FP8/AWQ), MLOps pipelines, and experience history.
- Pre-configured prompt chips for rapid technical inquiries.

### 4. Interactive Developer CLI Terminal
- High-tech Unix/Bash terminal emulator with autocomplete (`Tab`), history navigation (`↑`/`↓`), and rich command handlers:
  - `help`, `whoami`, `skills`, `ecosystem`, `projects`, `metrics`, `patents`, `download-cv`, `contact`, `clear`.

### 5. Procedural Web Audio Synthesizer
- Zero audio asset dependencies: procedural sci-fi UI beeps, sweeps, and action potential sound effects generated via Web Audio API.
- Integrated mute/audio toggle in the navbar.

## 🚀 How to Run

### Method 1: Double-Click (Zero Setup Required)
Simply double-click `index.html` in your file browser or open it directly in Google Chrome, Microsoft Edge, or Mozilla Firefox.

### Method 2: Local Node.js Server
From this directory, run:
```bash
npm start
```
Then navigate to:
```
http://localhost:3000
```

### Method 3: Run Integrity Test Suite
```bash
npm test
```
